# Just main bits

## Graph problem strategies
- Be sure to **explicitly describe a graph** in terms of problem parameters
- Convert problem in to finding shortest path, cycle, topological sort, connected components, etc.
- May help to duplicate graph vertices to encode additional information
	- e.g one vertice for different state (e.g tracking # of special nodes visited)
- May help to add auxiliary vertices/edges to graph
	- e.g when searching multiple locations in the same graph (add efficiency)
- May help to pre-process the graph (e.g to remove part of graph)
	- e.g some might be only traversed in one direction, or forbidden
